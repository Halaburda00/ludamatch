# ludamatch

Matches video game entries across stores — Steam, GOG, Epic — to one canonical
record.

Extracted from [Ludarium](https://github.com/Halaburda00/ludarium), a
self-hosted game library catalogue, and kept separate under MIT so that other
projects can depend on it without taking on Ludarium's AGPL.

Early: it holds what the first matching layer needs and nothing more yet.
